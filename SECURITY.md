# Security policy

## Supported versions

Only the **latest published version** (see [releases](https://github.com/sauveteur71/live-mesh-map-world/releases)) receives security fixes. Please update before reporting an issue, to confirm it still occurs.

## Reporting a vulnerability

If you find a security issue (authentication bypass, unintended access to an admin area, injection, data exposure, etc.), **please do not open a public issue**.

Report it preferably through this repository's **Security → Report a vulnerability** tab (private GitHub security advisory), or via a [private discussion](https://github.com/sauveteur71/live-mesh-map-world/discussions) clearly marked as sensitive, without detailing the flaw publicly.

Please include:
- the affected version;
- steps to reproduce;
- the potential impact (access, data, availability).

This project is maintained on volunteer time, so a response time cannot be guaranteed, but any serious report will be treated as a priority.
